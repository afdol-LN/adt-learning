# เอกสารเจตจำนงโครงการ (Project Intent Document)
## แพลตฟอร์มการเรียนรู้ด้วยตนเองสำหรับการเขียนโปรแกรมพื้นฐานแบบปรับตัวได้ (Adaptive Basic Programming Self-Learning Platform)

เอกสารฉบับนี้จัดทำขึ้นจากการประมวลผลเซสชันระดมความคิดและการตัดสินใจเพื่อกำหนดขอบเขตและเป้าหมายของระบบ โดยมีรายละเอียดโครงสร้างและแนวคิดหลักดังต่อไปนี้

### 1. หัวข้อหลัก (Topic)
* **หัวข้อ:** แพลตฟอร์มการเรียนรู้ด้วยตนเองสำหรับการเขียนโปรแกรมพื้นฐานแบบปรับตัวได้ (Adaptive Basic Program Self-Learning Platform)
* **กลุ่มเป้าหมาย:** ผู้เริ่มต้นเรียนเขียนโปรแกรมที่ต้องการพัฒนาทักษะอย่างเหมาะสมตามขีดความสามารถเฉพาะบุคคล

### 2. แนวคิดหลัก (Core Concept)
* **การดำเนินงานในรูปแบบด่าน (Stage-Based Implementation):**
  * ยกเลิกองค์ประกอบเกี่ยวกับเกม RPG หรือการใช้อวาตาร์ตัวละคร เพื่อให้ผู้เรียนจดจ่ออยู่กับเนื้อหาโดยไม่มีสิ่งเบี่ยงเบนความสนใจ
  * ปรับใช้ระบบการดำเนินเรื่องแบบด่านหรือระดับเชิงแนวคิดที่สะอาดและเป็นระเบียบ (Clean progression through conceptual stages)

### 3. การก้าวหน้าและปลดล็อกระดับ (Progression)
* **แผนภาพเชื่อมโยงความรู้ตามจริง (Goal-oriented Dependency Graph):**
  * แนวคิดในการเรียนรู้จะแสดงในลักษณะของด่านหรือระดับ (Stages/Levels) ที่เชื่อมโยงกันอย่างเป็นระบบ โดยงานทุกชิ้นจะเชื่อมต่อกับปลายทางที่ผู้เรียนต้องการเข้าถึงโดยตรง
  * เมื่อผู้เรียนผ่านการทดสอบในด่านหนึ่งแล้ว ระบบจะปลดล็อกด่านถัดไปที่เชื่อมโยงกันทันที
  * มีการประยุกต์ใช้หน้าจอเดี่ยวเป็น "แผนผังแนวคิดเชิงโต้ตอบ" (Dynamic Concept Map Resolver) ที่ซึ่งผู้ใช้สามารถคลิกโหนดต่าง ๆ เพื่อเริ่มทำแบบฝึกหัดสั้น ๆ และอัปเกรดระดับทักษะความรู้ได้อย่างรวดเร็ว

### 4. การสลับเป้าหมายและเส้นทางคู่ขนาน (Branching/Goals)
* **สาขาเส้นทางคู่ขนาน (Multiple Parallel Branches):**
  * ออกแบบเส้นทางการเรียนรู้แบบขนานรองรับหลายเป้าหมาย เช่น พื้นฐาน Python (Python Basics), พื้นฐาน SQL (SQL Basics) เป็นต้น
  * ผู้เรียนมีอิสระในการสลับเปลี่ยนสาขาเป้าหมายการเรียนรู้หลัก (Switch Branches) ไปมาได้ตลอดเวลาตามความต้องการเรียนรู้ในขณะนั้น

### 5. ระบบวิเคราะห์โปรไฟล์ผู้เรียนแบบไดนามิก (Dynamic Profiler)
* **การประเมินทักษะต่อเนื่องแบบเรียลไทม์ (Continuous Real-Time Profiling):**
  * ระบบวิเคราะห์โปรไฟล์จุดเด่นและจุดด้อยของผู้เรียนอย่างต่อเนื่องเป็นรายบุคคล (Individualized Strength/Weakness Profiler) ผ่านข้อมูลการทำแบบฝึกหัด
  * แผนผังแนวคิดจะเปลี่ยนแปลงรูปร่าง (Deforming Concept Map) ตามสถานะความรู้ความเข้าใจจริงของผู้เรียนเพื่อมอบหมายแบบฝึกหัดสั้น (mini-quests) ที่เหมาะสมกับสภาวะดังกล่าวแบบไดนามิก
  * หลีกเลี่ยงการใช้ข้อสอบแบบคัดเกณฑ์เริ่มต้นจำนวนมาก (No upfront gatekeeping quiz) แต่ทดแทนด้วยกระบวนการประเมินผลเรียลไทม์
  * ไม่มีการล็อกเวลาหรือหน่วงเวลาการเรียนรู้ของระบบ (Zero time-gating) ผู้เรียนสามารถก้าวหน้าในระดับทักษะได้อย่างรวดเร็วอ้างอิงจากความสามารถที่ได้รับการพิสูจน์จริงผ่านโจทย์ของแพลตฟอร์ม (Fast-track acceleration)

### 6. รูปแบบของแบบฝึกหัด (Exercise Formats)
ทดแทนการเข้าฟังการเรียนการสอนวิดีโอยาว ๆ ด้วยการลงมือทำทันทีผ่านแบบฝึกหัดโต้ตอบย่อย (Immediate interactive micro-exercises) โดยประกอบไปด้วย:
* **โจทย์เติมคำในช่องว่างของโค้ด (Fill-in-the-Blank Code Snippets):** การกรอกคำสำคัญหรือสัญลักษณ์ที่ขาดหายไปในส่วนของโค้ดให้ระบบโปรแกรมสมบูรณ์
* **คำถามแบบปรนัย (Multiple-Choice Questions):** คำถามตัวเลือกในการทดสอบความเข้าใจเชิงทฤษฎี คอนเซปต์ หรือผลลัพธ์ของชุดคำสั่งนั้น ๆ
