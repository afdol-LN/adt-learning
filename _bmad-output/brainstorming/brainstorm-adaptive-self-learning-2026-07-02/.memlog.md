- (technique) started Worst Possible Idea
- (idea by coach) The Infinite Lecture Lock: Non-skippable 3-hour video lecture with eye-tracking restarts.
- (idea by user) Blind Level Assessment: Program cannot understand the user's level, leading to mismatches and abandonment.
- (idea by coach) One-Way Gate Assessment: A massive 100-question initial test that permanently locks users into a tier with no recovery.
- (idea by user) Irrelevant Exercise Loop: Exercises don't align with the goal's dependency path, preventing users from reaching their destination.
- (idea by coach) Rabbit Hole Traps: Failing an exercise redirects users to completely random nested prerequisite topics instead of target practice.
- (idea by user) Forced Pacing Bloat: Program forces a fixed multi-month timeline, making fast completion impossible even for advanced users.
- (idea by coach) Artificially Throttled Progress: Strict daily content drip with zero bypass or acceleration options.
- (insight) Insight 1: Replace lectures with immediate interactive micro-exercises.
- (insight) Insight 2: Continuous real-time assessment instead of an upfront gatekeeping quiz.
- (insight) Insight 3: Goal-oriented dependency graph where every task is directly linked to the user's destination.
- (insight) Insight 4: Zero time-gating; fast-track acceleration based purely on proven competence.
- (technique) started One Feature Only
- (idea by coach) The Dynamic Concept Map Resolver: A single interactive knowledge map where clicking nodes runs rapid exercises to expand user mastery.
- (idea by user) Individualized Strength/Weakness Profiler: System maps user's unique strengths and weaknesses to select tailored exercises.
- (idea by coach) Deforming Concept Map: A map that visually reflects strengths/weaknesses in real-time and serves tailored mini-quests.
- (technique) started SCAMPER Method
- (idea by coach) Reverse - Teach the AI: User proves mastery by fixing and explaining bugs to a virtual student AI.
- (idea by user) Fill-in-the-Blank Code Exercises: Substitute long-form text answers with interactive fill-in-the-blank snippets to complete a program.
- (idea by coach) Interactive Blanks for AI Teaching: Drag-and-drop or type code blanks to complete programs for the virtual student AI.
- (decision by user) Dungeon Crawler Theme: Platform is styled as a dungeon where concepts are rooms and exercises are traps to disarm.
- (decision by user) Branching Dungeon Wings: Each learning goal is a separate wing/branch, and users can freely switch wings at any time.
- (insight) Dungeon crawler concept matches perfectly with dynamic concept maps, using rooms as concept nodes, code-blank puzzles as traps, and branches as dungeon wings.
- (decision by user) Stage-Based progression: Dialed back the full RPG game elements; keep it as a clean stage/level progression without character avatars.
- (decision by user) Exercise formats: Mix of fill-in-the-blank snippets and multiple-choice questions.
