userprofile

Class: Userprofile | ไฟล์: entity/userprofile.entity.ts
🟣 User Profile & Academic JSONB Supported
ตารางหลักสำหรับเก็บข้อมูลผู้ใช้งาน นักศึกษา ข้อมูลการศึกษาระดับมหาวิทยาลัย และสถานะความก้าวหน้าในการเรียนรู้ (BKT Concept Map & Strength-Weakness Matrix) ในรูปแบบ JSONB เพื่อลดภาระการเขียน (Write Amplification) ของระบบ

📄 โครงสร้างคอลัมน์ (Data Structure)

ชื่อฟิลด์ (Field Name) ชื่อคอลัมน์ (Column) ชนิดข้อมูล (Type) คุณสมบัติ & เงื่อนไข (Attributes) คำอธิบาย (Description)
id id integer PK PrimaryGeneratedColumn รหัสประจำตัวผู้ใช้งาน (Auto Increment)
fullName fullName varchar(100) Required ชื่อ-นามสกุลของผู้เรียน
genderId genderId integer FK Default: 1 รหัสเพศอ้างอิงไปยังตาราง gender
birthDate birthDate varchar / Date Required วันเดือนปีเกิดของผู้ใช้งาน
campusId campusId integer FK Nullable รหัสวิทยาเขตที่ศึกษา
facultyId facultyId integer FK Nullable รหัสคณะที่ศึกษา
majorId majorId integer FK Nullable รหัสสาขาวิชาที่ศึกษา
username username varchar(20) Nullable ชื่อบัญชีสำหรับเข้าสู่ระบบ
password password varchar(80) Nullable รหัสผ่านที่เข้ารหัสแล้ว (Hashed Password)
status status enum (Status) Default: Status.ACTIVE สถานะบัญชีผู้ใช้ (ACTIVE / INACTIVE)
behaviorScore behaviorScore numeric(4,3) Nullable คะแนนพฤติกรรมการเรียนรู้
conceptMapState conceptMapState jsonb JSONB Nullable เก็บสถานะความเชี่ยวชาญ (BKT Concept Map & Progress %) ในแต่ละทักษะ
strengthWeaknessMatrix strengthWeaknessMatrix jsonb JSONB Nullable เก็บเมทริกซ์วิเคราะห์จุดแข็งและจุดอ่อนของผู้เรียน
role role enum (UserRole) Default: UserRole.USER สิทธิ์การใช้งานระบบ (USER, ADMIN, STAFF)
createdAt / updatedAt createdAt / updatedAt timestamp Default: CURRENT_TIMESTAMP วันเวลาที่สร้างและอัปเดตข้อมูลล่าสุด
